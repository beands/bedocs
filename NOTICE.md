# NOTICE

## BeDocs

BeDocs — русскоязычная платформа документации, основанная на open-source проекте [Blume](https://github.com/haydenbleasel/blume).

- **Исходный проект:** Blume (https://github.com/haydenbleasel/blume)
- **Версия upstream:** Blume 1.4.1 (тег `blume@1.4.1`, коммит `058d1b29f51df2648ea2e2d21d4f865883eefe18`)
- **Форк создан:** BeandsMedia

## Существенные изменения

- Переименование продукта: Blume → BeDocs
- npm-пакет: `blume` → `@beands/bedocs`
- CLI-команда: `blume` → `bedocs`
- Конфигурация: `blume.config.ts` → `bedocs.config.ts`
- Генерируемая директория: `.blume/` → `.bedocs/`
- Префикс переменных окружения: `BLUME_` → `BEDOCS_`
- Русский язык как основной (локаль по умолчанию `ru`)
- Фирменная тема BeDocs
- Шаблоны документации для проектов BeandsMedia (Synthix, Taskcraft CRM, BeandsBooker)
- Skills для AI-агентов на русском языке
- Документация на русском языке
